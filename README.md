# EDI Connector Mexico for Odoo

Odoo side of the EDIDSA EDI service for retail chains in Mexico (Walmart and others).
Data-only module (no Python): EDI documents log, connection status and security groups.

The EDI connection (AS2, identifiers, document set-up) is configured exclusively by EDIDSA.
